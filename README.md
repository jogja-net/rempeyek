# Rempeyek Bu Aviella

Repo landing page **Rempeyek Bu Aviella** (Fase 1).

## Struktur branch

- **`main`** → Production (Vercel)
- **`staging`** → Preview deployment untuk review Bu Aviella

Semua pekerjaan dilakukan di branch `staging`, lalu digabung ke `main` lewat Pull Request.

## Isi repo

- `main` — hanya berisi file README ini (branch kosong sebagai titik awal)
- `staging` — implementasi landing page (Next.js App Router + TypeScript + Tailwind CSS v4, SSG)

Implementasi lengkap, cara menjalankan, dan daftar data yang masih menunggu Bu Aviella
ada di `README.md` pada branch `staging`.
